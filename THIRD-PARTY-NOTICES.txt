Rogue Agents: other people's work that travels with it

The game and its lobby server are built on the libraries below. Each is used
unchanged, as its makers published it, and each comes with the notice its
licence asks to be kept. Thank you to all of them.

  SDL 3.4 (the window, the graphics device, sound, keyboard, mouse, controllers)
      https://libsdl.org                                the zlib licence
  SDL3-CS 3.4.20 (what lets a C# program call SDL)
      https://github.com/edwardgushchin/SDL3-CS         the zlib licence
  LiteNetLib 2.1.5 (reliable messages over UDP)
      https://github.com/RevenantX/LiteNetLib           the MIT licence
  .NET 10 (the runtime the game and the lobby server bring with them,
      and ASP.NET Core in the lobby server)
      https://dotnet.microsoft.com                      the MIT licence
      (what .NET is itself built on is listed in DOTNET-THIRD-PARTY-NOTICES.txt)
